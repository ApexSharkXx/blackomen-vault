# Bug Bounty

Technical workspace for building a repeatable authorized bug bounty methodology.

## Structure

- `methodology/` — the current end-to-end hunting process.
- `vulnerabilities/` — reusable vulnerability knowledge.
- `recon/` — recon workflows, commands, and automation.
- `labs/` — lessons extracted from training environments.
- `reports/` — sanitized report examples and writing lessons.
- `tools/` — scripts and utilities I build or maintain.
- `templates/` — reusable note and report templates.

## Rule

A note belongs here when it improves future testing.
