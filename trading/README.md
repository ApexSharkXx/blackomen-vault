# Trading

Research workspace for turning trading ideas into explicit rules and evidence.

## Structure

- `playbook/` — the current trading model and risk rules.
- `setups/` — exact setup definitions.
- `backtesting/` — test plans, datasets, and results.
- `reviews/` — structured trade and session reviews.
- `research/` — market questions and mentor claims being investigated.
- `templates/` — reusable test and review templates.

## Rule

```text
CLAIM → RULES → TEST → DATA → DECISION
```
